# Pitch deck

`OpsDesk_Idea_Submission.pdf` and `.pptx` are generated by `build_deck.js` (pptxgenjs) from the screenshots, charts and icons in `assets/`.

```bash
cd docs/presentation && npm install
NODE_PATH=docs/presentation/node_modules node docs/presentation/build_deck.js   # from the repo root
soffice --headless --convert-to pdf --outdir docs/presentation docs/presentation/OpsDesk_Idea_Submission.pptx
```

- Icons in `assets/icons/` are Lucide (ISC licence), rasterised to white PNGs.
- Charts in `assets/chart_*.png` are drawn with matplotlib and seaborn from measured prototype numbers.
- After writing the file, the script strips a stray paragraph-properties element that pptxgenjs emits for mixed-format bullets.
