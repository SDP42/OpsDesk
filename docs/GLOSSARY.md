# Glossary

OpsDesk borrows air-traffic words so the ops floor reads like a control tower. This page maps each term to plain language.

## Core metaphor

| Term | Plain meaning |
| --- | --- |
| **Flight** | A ticket (support case) |
| **Pilot** | The travel agency that raised the ticket |
| **Controller** | The TBO ops agent working the ticket |
| **Tower Chief** | The escalation manager |
| **Airport Director** | The ops lead who owns policy and reporting |
| **Airspace** | The set of flights you are looking at (demo or live) |

## Booking terms

| Term | Plain meaning |
| --- | --- |
| **TBOH** | TBO's booking ID, for example `TBOH-88213` |
| **Check-in** | When the guest arrives at the hotel |
| **LCD** | Last cancellation date: after it, cancelling costs money |
| **HCN** | Hotel confirmation number from the supplier |
| **Supplier** | The hotel, bedbank or wholesaler that fulfils the booking |

## Routing terms

| Term | Plain meaning |
| --- | --- |
| **Vectoring** | Choosing which controller gets a flight, with a reason |
| **Preset** | A routing policy: balanced, urgency first, regional affinity or fairness |
| **Runner-up** | The next-best controller, with the points they lost by |
| **Triage** | Flights not yet assigned to anyone |

## SLA terms

| Term | Plain meaning |
| --- | --- |
| **Wheels-Up clock** | The SLA timer, which shortens as check-in or LCD nears |
| **Fuel** | Time left on the clock, from full tank to empty |
| **At risk / Critical / Breached** | 60%, 85% and 100% of the time used |
| **Holiday pause** | Clock hours not counted on a regional public holiday |

## Conversation terms

| Term | Plain meaning |
| --- | --- |
| **Frequency** | A side conversation with named recipients, such as a supplier or finance |
| **Internal note** | A message only TBO staff see |
| **External reply** | A message the Pilot sees |
| **HandoffDiff** | The check on transfer showing who stays, joins or drops from a Frequency |
