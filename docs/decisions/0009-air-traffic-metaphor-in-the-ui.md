# 0009. Air-traffic metaphor in the UI

**Status:** accepted

## Context

Generic helpdesk vocabulary hides what matters in travel ops: time to the guest's arrival.

## Decision

Tickets are flights, the SLA is a fuel clock, routing is vectoring. Every technical term gets a plain-language hint (`<Term>`).

## Consequences

Memorable and on-theme. The glossary and hints keep it understandable for new users.
