# Glossary

OpsDesk borrows air-traffic words so the ops floor reads like a control tower. This page maps each term to plain language.

## Core metaphor

| Term | Plain meaning |
| --- | --- |
| **Flight** | A ticket (support case) |
| **Pilot** | The travel agency that raised the ticket |
| **Controller** | The TBO ops agent working the ticket |
| **Tower Chief** | The escalation manager |
| **Airport Director** | The ops lead who owns policy and reporting |
| **Airspace** | The set of flights you are looking at (demo or live) |
