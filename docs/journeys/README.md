# Demo journeys

Each journey is a short, scripted path through the app that proves one part of the brief. All of them run as Playwright tests
(`make e2e`, with `make seed` and `make dev` running). The global setup reseeds the database first, so results are repeatable.

| Journey | Proves |
| --- | --- |
| [A](journey-a.md) | Context and linkage (Problem 1) |
| [B](journey-b.md) | Routing with a reason (Problem 2) |
| [C](journey-c.md) | Side conversations survive a handoff (Problem 3) |
| [D](journey-d.md) | Travel-aware SLA and escalation (Problem 4) |
| [E](journey-e.md) | Insights and uncapped export (Problems 5 and 6) |
| [F](journey-f.md) | A ghost flight dissolves |
| [G](journey-g.md) | Storm cell and broadcast |
| [H](journey-h.md) | Crew roster rebalances orphaned flights |
| [I](journey-i.md) | Wall Mode and the Autopilot |
| [J](journey-j.md) | Constellation and Follow-the-Sun |
